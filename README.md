# 中育ToolBox · 保存版

对已停止运营的「中育ToolBox」做的一个本地保存版：登录中育账号即可继续使用云笔记、图库、错题本、新测评、在线专栏等原有功能，不依赖作者服务器。

> 本工具与中育智慧（无锡）数字技术有限公司及其关联公司无关，仅供学习交流使用。

## 功能

- **云笔记**：浏览 / 搜索 / 图片预览 / 导出 PDF / 打包下载 / 回收站
- **图库**：浏览 / 上传（官方 imagestore 接口）/ 回收站
- **错题本、新测评、在线专栏、选课、优客畅学、随身答（只读）**
- **应用下载**：官方应用商店接口，获取 7 个应用的最新安装包
- **系统信息**：待办、学校设置、相机/相册/截屏许可、系统消息、话题等
- **Windows 宿主**：内置本地代理、端口固定可自定义、支持局域网/外网访问

## 下载

见 [Releases](../../releases)：Windows 便携版 / Windows 安装版 / 安卓版 APK

## 使用

### Windows

- 便携版：解压后运行 `中育ToolBox.exe`，浏览器自动打开
- 安装版：双击安装，从开始菜单或桌面启动
- 状态窗的「设置…」里可修改端口与监听范围（本机 / 局域网 / 外网）

### 安卓

- 安装 APK 后打开即自动建站（前台服务保活），点「在浏览器中打开」使用
- 建议开启「忽略电池优化」，只监听本机 127.0.0.1，不对外网开放

## 登录

- 学校选「省锡中双语学校」，或选「其它学校」后输入学校代码
- 不同学校后端独立、数据不互通，请与账号所属学校一致
- 账号密码为中育账号

## 构建

| 部分 | 方法 |
|---|---|
| 前端 | `npm install && npm run build`（产物在 `dist/`） |
| Windows 宿主 | 见 `host/`（运行 `host/assemble.py` 一键发布），需 .NET 9 SDK |
| 安卓 | 见 `android/`（aapt2 + javac + d8 命令行构建，无需 Gradle） |
| 打包 | `host/assemble.py` 完成发布与目录归拢 |

## 目录说明

```
├─ src/            前端源码（Vue 3 + Vite）
├─ host/           Windows 宿主源码（C#，含内置本地代理）
├─ android/        安卓版源码（Java，零依赖命令行构建）
├─ docs/           改动清单与测试说明
└─ dist/           前端构建产物
```
